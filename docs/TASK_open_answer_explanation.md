# Задача: Самостоятельная проверка ответов на открытые вопросы

## Проблема

Для вопросов типа `open_ended` (часть 2 ЕГЭ) у ученика был только один способ получить обратную связь — заплатить 10 монет и дождаться проверки репетитора. Поле `explanation` (эталонный ответ/пояснение), которое задаётся в админке, для открытых вопросов нигде не показывалось.

## Что сделано

Добавлена возможность самостоятельной проверки: после того как ученик сохранил свой ответ, появляется блок «Пояснение к ответу» с кнопкой «Посмотреть». При нажатии разворачивается эталонный текст из поля `explanation`, который задан администратором. Ученик сверяет свой ответ с пояснением и может переходить к следующему вопросу без запроса проверки репетитора.

## Изменения в БД, Backend, Admin

**Не требуются.** Поле `explanation` уже существует в модели `quiz_questions` и приходит с API для всех вопросов. В admin-панели оно уже редактируется через форму вопроса.

## Frontend

### `frontend/src/components/quiz/OpenAnswerInput.tsx`

**Новый проп:**
```typescript
explanation?: string | null
```

**Новое состояние:**
```typescript
const [showExplanation, setShowExplanation] = useState(false);
```

Состояние сбрасывается при смене вопроса (`questionId` в `useEffect`).

**Условие показа блока:**
```typescript
const canSeeExplanation = !!explanation && isSaved && !isDirty;
```
Блок появляется только если:
- у вопроса есть пояснение (задано в админке)
- ученик уже сохранил свой ответ
- ответ не был изменён с момента сохранения

**Новый UI-блок** (карточка с зелёным фоном, `teal`):
- Заголовок «Пояснение к ответу» с иконкой книги
- Кнопка «Посмотреть» / «Скрыть» (переключает `Collapse`)
- Пока скрыто: подсказка «Сверьте свой ответ с эталоном — проверка репетитора необязательна»
- После раскрытия: текст пояснения с сохранёнными переносами строк

**Разделитель** между блоком пояснения и блоком «Запросить проверку»:
```
──── или получить оценку репетитора ────
```
Разделитель появляется только если у вопроса есть пояснение, чтобы визуально разделить два пути.

## UX-сценарий

1. Ученик видит вопрос типа «Развёрнутый ответ (часть 2 ЕГЭ)»
2. Пишет ответ в textarea, нажимает «Сохранить ответ»
3. Появляется зелёный блок «Пояснение к ответу» с кнопкой «Посмотреть»
4. Ученик нажимает — разворачивается эталонный текст, заданный в админке
5. Ученик сверяет свой ответ с пояснением и нажимает «Далее →»
6. Тест завершается в обычном режиме, монеты начисляются за тест целиком

Кнопка «Запросить проверку у преподавателя (10 монет)» остаётся доступной — если ученик хочет получить персональный комментарий и оценку.

## Как настроить пояснение в Админке

Администратор задаёт текст в поле **«Пояснение»** при создании или редактировании вопроса типа `open_ended` в разделе «🧪 Тесты». Если поле пустое — блок пояснения не появится у ученика.
