# Задача: Прокрутка и цвет текста в Генетическом калькуляторе

## Проблемы

### 1. Нет вертикальной прокрутки при прохождении сценария
При переходе по шагам сценария, когда карточек накапливалось много, страница не прокручивалась — кнопка «Далее» уходила за нижний край экрана и была недоступна.

**Причина:** `PlayScreen` рендерился в `<div>` с `maxWidth` и `padding`, но без явной высоты и `overflow`. Прокрутка зависела от родительского контейнера Mantine-layout, который имеет `overflow: hidden` — контент обрезался, а не прокручивался. `position: sticky` на шапке работает только при наличии прокручиваемого предка.

### 2. Серый текст в карточках шагов
Текст заголовка шага (`step.title`) и тело шага (`step.content`) отображались серым, а не чёрным.

**Причина:** Отсутствие явного `color` у элементов — наследовался `color: dimmed` из Mantine-темы, применяемый к дочерним элементам по умолчанию.

## Что сделано

### `frontend/src/components/game/GeneticsGame.tsx`

**Прокрутка (`PlayScreen`):**

Обёртка компонента изменена с:
```jsx
<div style={{ maxWidth: 640, margin: "0 auto", padding: "0 0 40px" }}>
```
на:
```jsx
<div style={{
  maxWidth: 640,
  margin: "0 auto",
  height: "100vh",
  overflowY: "auto",
  display: "flex",
  flexDirection: "column",
}}>
```

Теперь `PlayScreen` создаёт собственную зону прокрутки высотой `100vh`, независимую от родительских контейнеров. Sticky-шапка (`position: sticky; top: 0`) корректно фиксируется внутри этого контейнера. Добавлено `flexShrink: 0` на шапку и `paddingBottom: 48px` на контейнер шагов, чтобы последняя карточка не обрезалась.

**Цвет текста (`StepCard`):**

```jsx
// Заголовок шага
<span style={{ fontWeight: 700, fontSize: 15, flex: 1, color: "#111" }}>

// Тело шага
<p style={{ margin: "0 0 14px", fontSize: 15, lineHeight: 1.6, whiteSpace: "pre-wrap", color: "#111" }}>
```
