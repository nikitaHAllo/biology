# 📋 План админ-панели для Biology EGE Platform

## 🎯 Общая концепция

Админ-панель для управления образовательной платформой по биологии с функциями:
- Управление контентом (курсы, уроки, квизы, материалы)
- Управление пользователями и их прогрессом
- Проверка заданий (assignments)
- Аналитика и статистика
- Управление экономикой (репкоины, транзакции)

---

## 📁 Структура админ-панели

### 1. **Dashboard (Главная страница)**
   - Общая статистика:
     - Количество пользователей (всего, активных за период)
     - Количество курсов, уроков, квизов
     - Общее количество репкоинов в системе
     - Количество проверенных/непроверенных заданий
   - Графики:
     - Регистрации пользователей по дням
     - Активность пользователей
     - Популярные курсы/квизы
   - Последние действия:
     - Недавние регистрации
     - Последние прохождения квизов
     - Новые отправки заданий

---

### 2. **Управление пользователями (Users Management)**

#### 2.1. Список пользователей
   - Таблица со всеми пользователями
   - Фильтры:
     - По telegram_id
     - По username
     - По дате регистрации
     - По балансу репкоинов
   - Колонки:
     - ID, Telegram ID, Username
     - Баланс репкоинов
     - Дата регистрации
     - Количество пройденных уроков
     - Количество достижений
     - Действия (просмотр, редактирование)

#### 2.2. Детальная страница пользователя
   - Основная информация:
     - Telegram ID, Username
     - Баланс репкоинов (с возможностью изменения)
     - Дата регистрации
   - Прогресс:
     - Список пройденных уроков с статусами
     - Прогресс по курсам
     - Результаты квизов
   - Достижения:
     - Список полученных достижений
     - Возможность вручную добавить достижение
   - Транзакции:
     - История всех транзакций (кредит/дебит)
     - Фильтры по типу, источнику, дате
     - Возможность добавить транзакцию вручную
   - Материалы:
     - Список купленных материалов
   - Задания:
     - История отправленных заданий
     - Статусы проверки

#### 2.3. Редактирование пользователя
   - Изменение баланса репкоинов
   - Добавление/удаление достижений
   - Блокировка/разблокировка (если будет реализовано)

---

### 3. **Управление курсами (Courses Management)**

#### 3.1. Список курсов
   - Таблица всех курсов
   - Колонки: ID, Название, Описание, Количество уроков, Дата создания
   - Действия: просмотр, редактирование, удаление

#### 3.2. Создание/редактирование курса
   - Поля:
     - Название (title)
     - Описание (description)
   - Список уроков курса:
     - Отображение всех уроков
     - Возможность изменить порядок (order_index)
     - Добавление/удаление уроков

---

### 4. **Управление уроками (Lessons Management)**

#### 4.1. Список уроков
   - Таблица всех уроков
   - Фильтры:
     - По курсу
     - По названию
   - Колонки: ID, Название, Курс, Порядок, Количество заданий, Дата создания
   - Действия: просмотр, редактирование, удаление

#### 4.2. Создание/редактирование урока
   - Основная информация:
     - Курс (выбор из списка)
     - Название (title)
     - Содержание (content) - текстовый редактор
     - Порядок (order_index)
   - Задания урока:
     - Список всех заданий урока
     - Добавление нового задания
     - Редактирование/удаление заданий

---

### 5. **Управление заданиями (Tasks Management)**

#### 5.1. Список заданий
   - Таблица всех заданий
   - Фильтры:
     - По уроку
     - По типу (single/multiple/text)
   - Колонки: ID, Вопрос, Урок, Тип, Награда (репкоины), Дата создания
   - Действия: просмотр, редактирование, удаление

#### 5.2. Создание/редактирование задания
   - Основная информация:
     - Урок (выбор из списка)
     - Тип задания:
       - single (одиночный выбор)
       - multiple (множественный выбор)
       - text (текстовый ответ)
     - Вопрос (question)
     - Варианты ответов (options) - JSON редактор
     - Правильный ответ (answer) - JSON редактор
     - Награда в репкоинах (reward_coins)

---

### 6. **Управление квизами (Quizzes Management)**

#### 6.1. Список квизов
   - Таблица всех квизов
   - Фильтры:
     - По статусу (активный/неактивный)
     - По названию
   - Колонки: ID, Название, Количество вопросов, Баллы, Статус, Дата создания
   - Действия: просмотр, редактирование, удаление, активация/деактивация

#### 6.2. Создание/редактирование квиза
   - Основная информация:
     - Название (title)
     - Описание (description)
     - Общее количество вопросов (total_questions) - автоматически
     - Общее количество баллов (total_points) - автоматически
     - Оценка времени в минутах (estimated_minutes)
     - Статус активности (is_active)
   - Вопросы квиза:
     - Список всех вопросов с порядком
     - Добавление нового вопроса
     - Редактирование/удаление вопросов
     - Изменение порядка вопросов

#### 6.3. Управление вопросами квиза
   - Создание/редактирование вопроса:
     - Текст вопроса (question_text)
     - Тип вопроса:
       - single_choice (одиночный выбор)
       - multiple_choice (множественный выбор)
       - true_false (верно/неверно)
     - Порядок (order_index)
     - Баллы за вопрос (points)
     - Таймер в секундах (timer_seconds) - опционально
     - Объяснение (explanation) - опционально
   - Варианты ответов:
     - Список вариантов
     - Добавление варианта:
       - Текст варианта (option_text)
       - Правильность (is_correct)
       - Порядок (order_index)
     - Редактирование/удаление вариантов

#### 6.4. Результаты квизов
   - Список всех прохождений квизов пользователями
   - Фильтры:
     - По квизу
     - По пользователю
     - По дате
     - По статусу (прошел/не прошел)
   - Колонки: Пользователь, Квиз, Баллы, Заработано репкоинов, Дата прохождения
   - Детальный просмотр результата

---

### 7. **Управление материалами (Materials Management)**

#### 7.1. Управление секциями материалов
   - Список секций
   - Колонки: ID, Название, Slug, Описание, Порядок, Количество тем
   - Действия: просмотр, редактирование, удаление

#### 7.2. Создание/редактирование секции
   - Название (title)
   - Slug (уникальный идентификатор)
   - Описание (description)
   - Иконка (icon) - опционально
   - Порядок (order_index)

#### 7.3. Управление темами материалов
   - Список тем (с фильтром по секции)
   - Колонки: ID, Название, Секция, Цена (репкоины), Бесплатная, Порядок
   - Действия: просмотр, редактирование, удаление

#### 7.4. Создание/редактирование темы
   - Основная информация:
     - Секция (выбор из списка)
     - Название (title)
     - Slug (уникальный идентификатор)
     - Описание (description)
     - Цена в репкоинах (price_repcoins)
     - Бесплатная по умолчанию (is_default_unlocked)
     - Порядок (order_index)
   - Файлы темы:
     - Список всех файлов
     - Загрузка нового файла:
       - Название файла (name)
       - Загрузка файла (file_url)
       - Тип файла (word/pdf/zip/other)
       - Размер файла (file_size) - автоматически
     - Редактирование/удаление файлов

#### 7.5. Статистика материалов
   - Популярные темы (по количеству покупок)
   - Доходы от материалов
   - Статистика доступа пользователей

---

### 8. **Управление заданиями для проверки (Assignments Management)**

#### 8.1. Список заданий
   - Таблица всех заданий
   - Фильтры:
     - По уроку
     - По названию
   - Колонки: ID, Название, Урок, Требования, Дата создания
   - Действия: просмотр, редактирование, удаление

#### 8.2. Создание/редактирование задания
   - Основная информация:
     - Урок (выбор из списка)
     - Название (title)
     - Требования (requirements) - текстовый редактор
     - Элементы ответа (answer_elements) - JSON редактор

#### 8.3. Отправки заданий (Submissions)
   - Список всех отправок
   - Фильтры:
     - По заданию
     - По пользователю
     - По статусу (pending/reviewing/graded/rejected)
     - По дате
   - Колонки: ID, Пользователь, Задание, Статус, Дата отправки, Ревьюер
   - Действия: просмотр, проверка

#### 8.4. Проверка отправки
   - Информация о задании:
     - Название, требования
   - Информация о пользователе:
     - Telegram ID, Username
   - Отправленный файл:
     - Просмотр/скачивание файла
   - Форма проверки:
     - Оценка (score) - от 0 до 100
     - Комментарий (comment)
     - Чеклист (checklist) - JSON редактор
     - Кнопки: Сохранить, Отклонить, Принять
   - История проверок:
     - Список всех проверок этой отправки

---

### 9. **Управление достижениями (Achievements Management)**

#### 9.1. Список достижений
   - Таблица всех достижений
   - Колонки: ID, Код, Название, Описание, Количество награждений, Дата создания
   - Действия: просмотр, редактирование, удаление

#### 9.2. Создание/редактирование достижения
   - Код (code) - уникальный идентификатор
   - Название (title)
   - Описание (description)

#### 9.3. Награждения пользователей
   - Список всех награждений
   - Фильтры:
     - По достижению
     - По пользователю
     - По дате
   - Возможность вручную наградить пользователя

---

### 10. **Управление загружаемыми задачами (Downloadable Tasks Management)**

#### 10.1. Список задач
   - Таблица всех задач
   - Фильтры:
     - По источнику (ege/fipi/other)
     - По году
     - По предмету
   - Колонки: ID, Название, Источник, Год, Тип файла, Размер, Дата создания
   - Действия: просмотр, редактирование, удаление

#### 10.2. Создание/редактирование задачи
   - Название (title)
   - Источник (source): ege/fipi/other
   - Описание (description)
   - Загрузка файла (file_url)
   - Тип файла (file_type): word/pdf/zip/other
   - Размер файла (file_size) - автоматически
   - Год (year) - опционально
   - Предмет (subject) - опционально

#### 10.3. Управление коллекциями задач
   - Список коллекций
   - Создание/редактирование коллекции:
     - Название (title)
     - Источник (source)
     - Описание (description)
     - Общий размер (total_size) - автоматически
   - Управление задачами в коллекции:
     - Добавление/удаление задач
     - Изменение порядка

## 🔐 Система авторизации

### Роли пользователей
- **Super Admin** - полный доступ ко всем функциям
- **Admin** - доступ к управлению контентом и проверке заданий
- **Moderator** - доступ только к проверке заданий и просмотру статистики

### Функции авторизации
- Вход по логину/паролю или через Telegram
- Двухфакторная аутентификация (опционально)
- Сессии и токены доступа
- Логирование действий администраторов

## 🔧 Технические требования

### Backend API
- Создать новые роуты для админ-панели:
  - `/api/admin/*` - все админские эндпоинты
  - Middleware для проверки прав доступа
  - Валидация данных на сервере

### Frontend
- Отдельный роутинг для админ-панели
- Защищенные маршруты
- Интеграция с существующим API
- Использование существующих компонентов где возможно

### Безопасность
- CSRF защита
- XSS защита
- Валидация всех входных данных
- Логирование подозрительной активности
- Rate limiting для API

## 🚀 Рекомендации по реализации

1. **Использовать существующую структуру проекта**
   - Расширить существующие модели при необходимости
   - Использовать существующие сервисы
   - Следовать существующим паттернам кода

2. **Создать отдельный модуль админки**
   - `backend/src/api/admin/` - админские роуты и контроллеры
   - `frontend/src/admin/` - админские компоненты и страницы
   - Минимальное влияние на существующий код

3. **Использовать готовые библиотеки**
   - Для таблиц: react-table или ag-grid
   - Для форм: react-hook-form
   - Для графиков: recharts или chart.js
   - Для UI компонентов: Material-UI, Ant Design или shadcn/ui

4. **Тестирование**
   - Unit тесты для критичных функций
   - E2E тесты для основных сценариев
   - Тестирование безопасности
