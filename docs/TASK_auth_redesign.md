# Задача: Редизайн страниц логина и регистрации

## Проблема
- Форма была зажата в `Container size={420}` — 420px максимум, выглядело как мобильный лейаут даже на широких экранах
- Разные фоновые градиенты на `/login` и `/register`:
  - Login: `#1b4332 → #2b7a78 → #3aafa9`
  - Register: `#0d2818 → #1b4332 → #2d6a4f`
- Нет адаптива: одинаково узкая форма на телефоне и на большом мониторе

## Что сделано

### Файлы
- **`frontend/src/pages/Login.tsx`** — полный редизайн
- **`frontend/src/pages/Register.tsx`** — полный редизайн

### Единый фон
Оба файла теперь используют одинаковый градиент:
```
linear-gradient(135deg, #050d18 0%, #071a0e 55%, #050d18 100%)
```
Тёмный, с едва заметным зелёным оттенком — совпадает с общей тёмной темой приложения.

### Split-layout (десктоп ≥ 768px)
Карточка `maxWidth: 900px` разделена на две колонки:

**Левая панель** (фиксированная, 380px, `visibleFrom='sm'`):
- Тёмно-зелёный градиент (`#052e16 → #064e3b → #065f46`)
- Иконка листа 56px
- Название «БиоЛаб» + подзаголовок
- Список из 4 фич платформы с иконками (Биосадовник, Генетика, Вирусный детектив, Тесты)

**Правая панель** (белая, `flex: 1`):
- Заголовок + описание
- Поля формы `size='md'` (крупнее прежних)
- Кнопка `size='md'`
- Ссылка на другую страницу

### Мобилка (< 768px)
Левая панель скрывается (`visibleFrom='sm'` → `display: none`).
Правая панель занимает всю ширину карточки.
В верхней части формы появляется компактная шапка (`hiddenFrom='sm'`) с иконкой и названием.

### Карточка
```
maxWidth: 900px
borderRadius: 20px
boxShadow: 0 32px 80px rgba(0,0,0,0.55)
overflow: hidden
minHeight: 520px
```

## Изменений в БД / бэкенде нет
Только визуальные изменения фронтенда. Логика логина/регистрации не тронута.
