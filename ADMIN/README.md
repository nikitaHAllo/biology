# Biology EGE Platform - Admin Panel

Админ-панель для управления образовательной платформой по биологии.

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **React Router** - маршрутизация
- **Tailwind CSS** - стилизация
- **React Query** - управление состоянием (готово к использованию)
- **Recharts** - графики и диаграммы
- **Lucide React** - иконки

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Переменные окружения

Создайте файл `.env`:

```
VITE_API_URL=http://localhost:8000
```

## Авторизация

Для входа используйте любой логин и пароль (демо-режим без бэкенда).

## Структура проекта

```
├── src/
│   ├── components/          # React компоненты
│   │   └── layout/         # Компоненты layout
│   ├── hooks/              # React хуки
│   ├── lib/                # Утилиты и хелперы
│   │   ├── api/            # API клиент (готов к использованию)
│   │   └── types/          # TypeScript типы
│   ├── pages/              # Страницы приложения
│   ├── App.tsx             # Главный компонент с роутингом
│   ├── main.tsx            # Точка входа
│   └── index.css           # Глобальные стили
├── index.html              # HTML шаблон
└── vite.config.ts          # Конфигурация Vite
```

## Реализованные страницы

- ✅ **Dashboard** - главная страница со статистикой
- ✅ **Пользователи** - список и детальная страница пользователя
- ✅ **Квизы** - список и редактирование квизов
- ✅ **Задания** - список отправок и проверка заданий

## Особенности

- Минимальная авторизация (локальное хранилище)
- Адаптивный дизайн
- Современный UI с Tailwind CSS
- Готово к интеграции с бэкендом (API клиент настроен)
